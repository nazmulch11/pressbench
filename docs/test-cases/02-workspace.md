# Test cases: Workspace shell (TC-WS)

The workspace opens with a demo plugin project held in memory (`my-plugin/` with `my-plugin.php`, `readme.txt`,
`assets/style.css` and `includes/class-my-plugin.php`). No Playground boot is needed for these cases; the Phase 1
spike panel sits in the preview area and stays idle. All `e2e` cases run in Chromium, Firefox and WebKit, 3 times
each. "Ctrl/Cmd" means Ctrl on Windows and Linux, Cmd on macOS.

## Notes

- TC-WS-013 is split into sub-cases `TC-WS-013a` to `TC-WS-013h` in `src/lib/fs/project-fs.test.ts` (one behaviour
  per test); the automation column of TC-WS-013 is that file.
- Drag and drop in the tree and the tab bar is built on pointer events, so Playwright drives it with `mouse.move`,
  `mouse.down` and `mouse.up` in every engine. Playwright's `dragTo` (HTML5 drag) is not used.
- `Ctrl/Cmd+W` is handled by the app, but browsers may still close their own tab on that shortcut. The tab's close
  button and the "Close tab" command are the alternatives; the e2e cases use those.
