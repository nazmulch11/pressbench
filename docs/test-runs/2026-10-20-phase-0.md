One thing to know: the very first pushes to the brand-new repository (the initial `main` push and the probe pull
request) produced no workflow runs at all, although Actions was enabled and the workflow was indexed. Runs only started
after a further push that added a second workflow file to the probe branch; from then on every push and pull request
ran normally. If a new repository shows no runs, push once more before suspecting the workflow.
