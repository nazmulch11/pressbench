A separate reviewer agent (which had not seen the work) checked the code against the coding standards and found 12
problems. All were fixed with tests written first (TC-FND-007a, TC-FND-010i to TC-FND-010m), then every check above
was run again: `npm run check` passes, and E2E passes 21/21 runs in Chromium. Details are in `CHANGELOG.md` under
"Fixed". The most important: the React lint rules had been silently disabled by a config merge, and skipped or
commented-out tests could have counted as automated.
