# Contributing

Thanks for helping build Pressbench.

1. Open or pick an issue. For a feature, write a short spec with [docs/templates/feature-spec.md](docs/templates/feature-spec.md).
2. Create a branch: `feat/…`, `fix/<issue>-…`, `docs/…`, `test/…`, `chore/…`.
3. Follow the task workflow in [AGENTS.md](AGENTS.md#how-to-do-a-task-follow-every-time): test cases first, tests,
   code, checks, real-browser check, docs.
4. Follow [docs/CODING_STANDARDS.md](docs/CODING_STANDARDS.md).
5. Open a pull request and complete every item in the template.

Bugs: use [docs/templates/bug-report.md](docs/templates/bug-report.md) and follow [docs/DEBUGGING.md](docs/DEBUGGING.md).
